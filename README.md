# basketball

Research on probabilistic forecasting of NBA player statistics and game outcomes.

- [`docs/research/nba_sequence_modeling.md`](docs/research/nba_sequence_modeling.md): a first-principles look at information theory, Markov and state-space models, simulation, and modern ML for NBA prediction. Covers which ideas really apply, proposed falsification experiments, and a full system design.
- [`experiments/toy_demos.py`](experiments/toy_demos.py): toy numerical demonstrations referenced in the document (`pip install numpy scipy && python3 experiments/toy_demos.py`).
